# Neural Networks

## Introduction to Neural Networks

Neural Networks are computing systems inspired by biological neural networks in animal brains. They consist of interconnected nodes (neurons) that process information using connectionist approaches to computation.

## Basic Components

### Neurons (Nodes)
- Basic computational units
- Receive inputs from other neurons
- Apply weights and activation functions
- Produce outputs to other neurons

### Connections (Weights)
- Strength of connections between neurons
- Learned during training
- Determine signal strength
- Can be positive (excitatory) or negative (inhibitory)

### Activation Functions
- Introduce non-linearity
- Enable complex pattern learning
- Common types: Sigmoid, ReLU, Tanh
- Determine neuron output

## Types of Neural Networks

### Feedforward Neural Networks
- Information flows in one direction
- Input → Hidden → Output layers
- No cycles or loops
- Used for: classification, regression

### Convolutional Neural Networks (CNNs)
- Specialized for grid-like data (images)
- Convolutional layers for feature detection
- Pooling layers for dimensionality reduction
- Used for: image recognition, computer vision

### Recurrent Neural Networks (RNNs)
- Process sequential data
- Memory of previous inputs
- Hidden states carry information
- Used for: time series, text processing

### Long Short-Term Memory (LSTM)
- Advanced RNN architecture
- Solves vanishing gradient problem
- Gates for information control
- Used for: language modeling, speech recognition

### Transformer Networks
- Attention-based architecture
- Processes all tokens simultaneously
- Self-attention mechanisms
- Used for: NLP, vision tasks

## Training Process

### Forward Propagation
- Input data through network
- Compute layer outputs
- Generate predictions
- Calculate loss/error

### Backpropagation
- Calculate gradients
- Propagate errors backward
- Update weights
- Minimize loss function

### Optimization Algorithms
- Gradient Descent: Basic weight updates
- Stochastic GD: Random sample updates
- Adam: Adaptive learning rates
- RMSprop: Adaptive momentum

## Activation Functions

### Sigmoid
- Range: 0 to 1
- Smooth gradient
- Used for: binary classification
- Problem: Vanishing gradients

### ReLU (Rectified Linear Unit)
- Range: 0 to ∞
- Simple computation
- Used for: hidden layers
- Problem: Dead neurons

### Tanh
- Range: -1 to 1
- Zero-centered
- Used for: hidden layers
- Problem: Vanishing gradients

### Softmax
- Range: 0 to 1 (sums to 1)
- Multi-class probability
- Used for: output layer
- Good for: classification

## Deep Learning Concepts

### Deep Neural Networks
- Multiple hidden layers
- Hierarchical feature learning
- Complex pattern recognition
- Requires large datasets

### Transfer Learning
- Pre-trained models
- Fine-tuning for specific tasks
- Reduces training time
- Leverages existing knowledge

### Regularization
- Dropout: Random neuron removal
- L1/L2: Weight penalty
- Batch normalization: Layer normalization
- Early stopping: Prevent overfitting

## Common Architectures

### LeNet-5
- Early CNN for digit recognition
- Convolution + pooling layers
- Pioneered modern CNNs
- Used for: MNIST classification

### AlexNet
- Deep CNN for ImageNet
- ReLU activation
- Dropout regularization
- Won ImageNet 2012

### VGG Networks
- Very deep CNNs
- Small 3x3 filters
- Uniform architecture
- Used for: feature extraction

### ResNet (Residual Networks)
- Skip connections
- Very deep networks
- Solves vanishing gradients
- State-of-the-art performance

### BERT (Bidirectional Encoder Representations from Transformers)
- Pre-trained language model
- Bidirectional context
- Transformer architecture
- Used for: NLP tasks
